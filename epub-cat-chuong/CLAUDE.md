# EPUB Cắt Chương
PWA thuần HTML/CSS/JS (không build, không npm). Chỉ làm một việc: cắt epub theo khoảng chương A→B. Kế hoạch đầy đủ: kehoach-epub-cutter.md.
- Tên biến/file tiếng Anh; giao diện + comment tiếng Việt; hàm ngắn; try/catch mọi thao tác file, báo lỗi dễ hiểu.
- Không bao giờ sửa file gốc. JSZip ghim 3.10.1 trong assets/js.
- Sửa code xong nhớ đổi `V` trong sw.js.
- Chưa làm: nhớ file gần nhất; mục lục file mới chỉ có 1 dòng mỗi chương.
